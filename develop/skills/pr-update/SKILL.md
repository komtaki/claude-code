# PR 本文更新手順

## 更新手順

1. **タイトル・本文は `Agent` ツールで `develop:pr-writer` を起動して新規に書かせる。** 下書きしてから清書させると、その文章を捨てられない。PR 番号・ベースブランチ・差分から読み取れない経緯（事実のみ）を渡す
2. 書き出されたファイルを読んで検品する。直させる場合は、経緯に判断を足して書き直させる
3. タイトルと本文をまとめて反映する (`gh pr edit --title "..." --body-file <パス>`)
