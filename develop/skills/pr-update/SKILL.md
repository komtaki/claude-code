# PR 本文更新手順

## 更新手順

1. 既存本文を `gh pr view --json body` で確認し、差分から読み取れない事実（経緯、参照ドキュメントの URL、但し書き）だけを抜き出す。pr-writer は既存本文を読まないため、ここで拾わなければ落ちる
2. **タイトル・本文は `Agent` ツールで `develop:pr-writer` を起動して新規に書かせる。** 下書きしてから清書させると、その文章を捨てられない。PR 番号・ベースブランチと、手順 1 で抜き出した事実を渡す。文章表現は渡さない
3. 書き出されたファイルを読んで検品する。直させる場合は、経緯に判断を足して書き直させる
4. タイトルと本文をまとめて反映する (`gh pr edit --title "..." --body-file <パス>`)
