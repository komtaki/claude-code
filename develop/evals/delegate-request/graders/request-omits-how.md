最終メッセージに示された「developer に渡した依頼文」だけを見て判定する。

PASS: 依頼文が目的・要件・範囲・完了条件を述べ、文書（README など）に何を書くか・書かないかを指定していない。文書の扱いに触れる場合は、「作業先の文書規約に照らして判断する」といった問いや判断の委任になっている。
FAIL: 依頼文が文書に書く内容を指定している（例:「README に TINYRETRY_MAX の説明を追記する」「既定値 3 を README に書く」「使い方の節を足す」）、または実装の手順・コードの書き方（例:「retry_max で ${TINYRETRY_MAX:-3} を返す」）を指定している。依頼文が示されていない場合も FAIL。
